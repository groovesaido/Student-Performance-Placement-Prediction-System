# Student-Performance-Placement-Prediction-System
**Overview**

This project applies machine learning techniques to analyze and predict student academic performance and placement outcomes based on behavioral and academic features. It demonstrates both regression modeling (exam score prediction) and classification modeling (placement prediction) using structured,synthetic student data.

**Tasks**

1. Regression Task

Predict a student's exam score based on study habits and academic history.

2. Classification Task

Predict whether a student will be placed or not placed based on performance indicators.

**Dataset Features**

study_hours

attendance

sleep_hours

internet_usage

assignments_completed

previous_score

exam_score (target for regression)

placement_status (target for classification)
